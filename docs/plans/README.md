# Implementation Plans

Plans are first-class repo artifacts. Use them when work spans multiple files,
decisions, or sessions.

- `active/`: current work. Agents should read these before resuming related
  implementation.
- `completed/`: historical plans kept for decision context after work lands.
- `TEMPLATE.md`: copy this for new plans.

Move a plan from `active/` to `completed/` when the implementation has landed
and the final state is reflected in code, docs, and tests.
