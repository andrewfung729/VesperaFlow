# VesperaFlow Store

Persistence package for product-visible truth. PostgreSQL owns task, schedule,
run, template, occurrence override, and read-model state; Temporal owns durable
execution history and timers.

## Ownership

- `models.py`: SQLAlchemy ORM models.
- `repositories.py`: transaction-aware persistence operations.
- `database.py`: async engine/session helpers.
- `errors.py`: persistence-layer errors.
- `alembic/`: migration environment and versions.

## Alembic Workflow

Run migrations from this directory:

```bash
uv run alembic upgrade head
```

Create a migration:

```bash
uv run alembic revision --autogenerate -m "describe change"
```

Review autogenerated migrations before committing. They are implementation
artifacts, not design documents.

## Tests

Run store tests from the repository root:

```bash
uv run pytest packages/store/tests
```

Repository tests should cover transaction behavior, optimistic concurrency,
model constraints, and migration-sensitive persistence rules.
